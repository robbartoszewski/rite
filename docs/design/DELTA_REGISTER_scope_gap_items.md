**Flagged, not folded in** (terminating-check C): `rite publish install-ci` is a new command added at the terminating stage rather than a repair. Taken deliberately — the alternative was shipping four messages that prescribe a command which refuses — and it is a CLI surface onto `write_ci_workflow`, which already existed and was already tested, mirroring `install-hook` line for line. It is called out here rather than passed off as a fix.

**Register completeness** (terminating-check C): rows 1–21 record round-1 deltas only.

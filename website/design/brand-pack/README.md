# rite — brand assets

Generated from the final logo export. Everything derived from one source, so all sizes are consistent.

## Colors
- Crimson (primary):  #B82D22
- Ember / amber:      #E8743B
- Ink (wordmark):     #211E1B
- Off-white (bg):     #FAF7F2

## Contents
- logo/      full lockup (transparent, light bg, 1024, horizontal variant)
- mark/      flame only (transparent, tight + 1024 padded)
- favicon/   favicon.ico (16/32/48) + 16/32/48/64 PNG; favicon-tile-* = dark-tab-safe colored version
- app-icon/  apple-touch-icon (180, colored tile), icon-192/512 (transparent, "any"),
             maskable-512 (full-bleed, safe-zone), tile-192/512 (rounded app tile)
- monochrome/ mark + lockup in solid black and solid white (for 1-color contexts)
- social/    avatar-512 (square tile for GitHub/LinkedIn/X), og-banner-1200x630
- head-snippet.html + site.webmanifest  -> drop into a site's <head> / web root

## Notes
- Favicon is the flame mark only (no wordmark). Use favicon-tile-* if the flame looks muddy on dark browser tabs.
- These are raster (PNG/ICO) from a raster export. If you later get an SVG of the flame, send it and I'll regenerate crisp vector + exact-match set.
